# Diabetes-Risk-Prediction-by-Logistic-Regression-
Diabetes risk prediction using six machine learning models in Altair AI Studio (RapidMiner). Evaluated 768 records from the Pima Indians Diabetes Database using accuracy, AUC, precision, recall, and F1 score. Baseline Logistic Regression achieved 76.52% accuracy and 0.827 AUC, outperforming its tuned version.
